# TKDH2D – Thiết kế đồ họa 2D

## 1. Giới thiệu

Đây là project học tập môn Thiết kế đồ họa 2D, tập trung vào việc thiết kế poster bằng Adobe Illustrator. Các sản phẩm hướng đến bố cục rõ ràng, màu sắc hài hòa, đường nét đơn giản và truyền tải thông điệp phù hợp với từng chủ đề.

## 2. Danh sách sản phẩm

| STT | Tên sản phẩm | Chủ đề |
|---|---|---|
| 1 | `christmas.ai` | Poster Giáng sinh |
| 2 | `halloween.ai` | Poster Halloween |
| 3 | `tet.ai` | Poster Tết Nguyên đán |
| 4 | `thiep.ai` | Thiệp chúc mừng |
| 5 | `tudo.ai` | Poster tự do sáng tạo |
| 6 | `valentines.ai` | Poster Lễ tình nhân |

## 3. Công cụ sử dụng

- Adobe Illustrator
- Git
- GitHub

## 4. Cách xem và chỉnh sửa

1. Truy cập repository trên GitHub và tải project về máy.
2. Mở file `.ai` bằng Adobe Illustrator.
3. Có thể xem, chỉnh sửa và tiếp tục phát triển các sản phẩm thiết kế.

## 5. Mục tiêu

- Rèn luyện kỹ năng sử dụng Adobe Illustrator.
- Thực hành thiết kế poster theo nhiều chủ đề.
- Nâng cao khả năng phối màu, sắp xếp bố cục và truyền tải thông điệp bằng hình ảnh.
